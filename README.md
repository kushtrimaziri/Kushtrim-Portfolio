# Kushtrim Aziri — Portfolio

A dark, premium personal portfolio website built with semantic HTML, modern CSS, and vanilla JavaScript.

## Features
- Responsive desktop, tablet, and mobile layouts
- Featured projects for Bella Cucina, Aurelia Grand Hotel, and Siam Drift
- Direct live-demo and GitHub repository links
- Mobile navigation with Escape-key support
- Scroll reveal, progress indicator, and back-to-top control
- Keyboard focus styling and reduced-motion support
- No frameworks, build tools, or dependencies required

## Run locally
Open `index.html` in your browser, or use VS Code's Live Server extension.

## Before publishing
In `index.html`, replace `YOUR_EMAIL_HERE` in the contact button's `mailto:` link with the email address you want clients to use.

## Publish with GitHub Pages
1. Create a public GitHub repository, for example `kushtrim-portfolio`.
2. Upload all files and keep `index.html` at the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then save.
